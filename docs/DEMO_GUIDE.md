# Demonstration guide

## Guided walkthrough

1. Open the application and choose **Demo tools → Start guided walkthrough**.
2. Review the overview and the measurement-type labels.
3. Choose **Next** to inspect the heart-rate history. Hover, tap or use arrow keys on the chart. Daily views show one last sample per UTC day; minute views retain the available live samples.
4. Continue to the injected missing-oxygen state. Explain that this is a simulator action, not a detected medical event.
5. Continue into Help. Choose quick replies yourself; no response is supplied automatically. Source links and scope are visible. Use **Continue walkthrough** inside Help to proceed.
6. The next stage restores the simulated signal. It does not claim that the chat repaired a device.
7. Continue to the three-question check-in. You may enter sample answers and inspect their effects in the temporary session.
8. **Finish** or **Exit** returns to the original session. Walkthrough entries are discarded and do not overwrite saved local plans.

This is a presenter-controlled live interaction, not a video or a prerecorded cursor animation. You can pause by leaving the step unchanged. Synthetic vital signs continue updating while the page is visible.

## Explore the regular app

- Generate 7, 30 or 90 days from Demo tools. This replaces measurement history, not completed daily-plan records.
- Select Stable / Check needed / Urgent event / Missing sensor. These are explicit prepared scenarios, not diagnostic results.
- Select an available main metric to open Health. A pending wellbeing entry opens today's check-in; a missing SpO₂ reading opens the prepared sensor-check branch.
- Complete today's Daily plan. The illustrative activity target is 30 minutes; Recovery day has no numeric activity target. Record minutes, confirm measurement review and save a wellbeing check-in.
- Every honest wellbeing score counts equally toward task completion. Finishing all three tasks earns a calendar mark and a message; no medical performance score is awarded.
- Click a calendar day to inspect its saved entries. Empty previous dates stay empty; generated measurements do not invent completed tasks.
- Open Connection to inspect or download a report. Include histories, events or check-in notes only when wanted. Downloading does not notify anyone.

## Reset and access

**Clear demo data deletes saved local plans and check-ins.** For a demonstration that preserves those records, use the guided walkthrough instead.

The app needs no account. Source links open external websites. Local execution while a page is loaded does not establish support for offline installation or closed-page monitoring.
